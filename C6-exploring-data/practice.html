Practice with visual summaries

  1. Read in the following data sets:
  • faithful.csv
  • marathon.csv
  1. Summarize the following variables using an appropriate chart (bar chart, histogram, and / or boxplot):
  • faithful: eruptions
  • faithful: waiting
  • marathon: Age
  • marathon: State
  • marathon: Country
  • marathon: Official Time
# faithful: eruptions
ggplot(faithful, aes(x = eruptions)) + geom_histogram(binwidth = 0.25)
# faithful: waiting
ggplot(faithful, aes(x = waiting)) + geom_histogram(binwidth = 5)
# marathon: Age
ggplot(marathon, aes(x = Age)) + geom_histogram(binwidth = 5)
# marathon: State
marathon |> count(State) |>
    ggplot(aes(x = n, y = reorder(State, n))) + geom_col()
# marathon: Country
marathon |> count(Country) |>
    ggplot(aes(x = n, y = reorder(Country, n))) + geom_col()
# marathon: `Official Time`
ggplot(marathon, aes(x = as.numeric(`Official Time`) / 60)) +
    geom_histogram(binwidth = 15) + labs(x = "Official time (minutes)")
