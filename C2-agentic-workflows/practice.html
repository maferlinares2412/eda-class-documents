Commit to your partner’s repo

Pair up with a neighbor and work through the collaboration loop. You’ll both push straight to the mainbranch.

  1. In your eda-practice repo on GitHub.com: Settings › Collaborators → add your partner’s GitHub username → they accept the emailed invite
  2. Swap repo links. In GitHub Desktop: File › Clone Repository → clone your partner’s repo
  3. Edit their README.md in Positron → Commit to main → Push
  4. Back in your own repo, click Fetch origin, then Pull
  5. Open README.md — your partner’s edit should be there

Practice 2: Your first agentic project

Direct an agent to build a multi-page Quarto website about someone you admire — a scientist, athlete, artist, whoever.

  1. In GitHub Desktop, make a new repo called my-website (include a README file). Make it public, and publish it to GitHub.
  2. In Positron: File › Open Folder… and pick that repo’s folder.
  3. In the terminal pane, type claude and press Enter.
  4. Prompt Claude for a multi-page Quarto website about your person.
  5. When it’s done, ask it to render the site (if it didn’t already).
  6. Open index.html in the _site folder.
  7. Commit + push to GitHub.

Extra: publish with GitHub Pages

  1. Ask Claude to change the Quarto output folder from _site to docs (edit output-dir in _quarto.yml), then re-render.
  2. Commit + push.
  3. On GitHub.com: Settings › Pages → Source: Deploy from a branch, Branch: main, Folder: /docs → Save.
  4. Wait a minute, then visit the URL GitHub shows at the top of that page.

Practice 3: Modes & slash commands

Still in your my-website repo:

  1. Run /init — then open the CLAUDE.md it wrote and read it.
  2. Run /model and /effort to see your options.
  3. Ask for a small change (a new page, a navbar tweak) at /effort low.
  4. Press shift + tab into plan mode, then ask for something harder — e.g. “collapse everything into a single-page website” — at /effort high. Read the plan before you approve it.
  5. /compact, then keep going. Does it still know what you’re building?
  6. /clear, then ask “what am I working on?”
  7. Commit + push.

delay_by_airline <- flights |>
  left_join(airlines, by = "carrier") |>
  group_by(carrier, name) |>
  summarize(
    mean_dep_delay = mean(dep_delay, na.rm = TRUE),
    .groups = "drop"
